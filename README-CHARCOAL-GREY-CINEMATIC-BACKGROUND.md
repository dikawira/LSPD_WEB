# LSPD Charcoal Grey Theme + Cinematic Moving Background

- Global interface palette updated to charcoal/dark grey with silver accents.
- Main portal wallpaper uses a fixed, slow pan/zoom animation to create a video-like cinematic motion.
- The animated wallpaper is fixed to the viewport, so opening accordions or scrolling does not resize/zoom the background.
- Motion respects `prefers-reduced-motion`.
- Officer photos, uploaded media, and department emblems retain their original colours.
- Login/application shell styles in `src/app/globals.css` are also updated.

No database schema or stored officer/media data was changed.
